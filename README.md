# TP Java - Classe, héritage et polymorphisme

Application pédagogique simple : gestion des personnes d'un établissement (étudiants et enseignants).

## Contenu
- Personne : classe abstraite (nom, prénom, email)
- Etudiant : hérite de Personne (matricule, notes, moyenne)
- Enseignant : hérite de Personne (spécialité, nombre d'heures)
- Main : démonstration du polymorphisme

## Outils
IntelliJ IDEA, JDK 17 ou supérieur
